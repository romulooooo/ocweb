# PLAYBOOK

## Purpose
Reusable operating patterns for agents and contributors.

## Pattern 1: vision first execution
- Use the reference images as the main source
- Compare current and desired state visually
- Act conservatively

## Pattern 2: non vision fallback
- Read `SCREEN_INTENT.md`
- Read `VISUAL_RULES.md`
- Read `ocr/`
- Read `ui_state/`
- Derive the intended final state before acting

## Pattern 3: documentation update
- Update the nearest source of truth
- Keep names self explanatory
- Record major changes in `CHANGELOG.md` or `DECISIONS.md`
