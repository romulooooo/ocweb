# Vision

## Purpose
Build a repo that gives agents and humans a clear, professional, state of the art operating system for planning, interpreting, executing, validating, and handing off work.

## Core idea
The repo is not only source code. It is a structured execution environment.

## Desired outcome
- Agents understand the goal fast
- Agents with vision use images first
- Agents without vision use OCR and structured state as fallback
- Humans can audit decisions, rules, and progress
- Work can continue across sessions with low context loss

## Design principles
- Single source of truth per topic
- Explicit over implicit
- Minimal ambiguity
- Human readable and agent friendly
- Easy handoff between operators
