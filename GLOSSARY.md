# Glossary

## Current state
The state shown in the full screen reference image.

## Desired state
The state shown in the terminal only reference image.

## Vision agent
An agent that can directly inspect screenshots or UI images.

## Non vision agent
An agent that cannot inspect images and must rely on text, OCR, or structured state.

## OCR
Text extracted from images to help non vision interpretation.

## UI state
Structured representation of visible interface elements, usually in JSON.

## Memory
Persistent information that should be retained across related work.

## Context
Interpretation guidance about how to understand the repository and its files.

## Goal
The main outcome the agent should optimize for now.

## Roadmap
Phased progression of the project over time.
