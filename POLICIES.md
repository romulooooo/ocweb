# Policies

## Documentation policy
- Every important operating rule should exist in a named document
- DOCS_INDEX.md must point to all high value docs
- Source of truth should be explicit

## Change policy
- Update related docs when behavior changes
- Record meaningful decisions in DECISIONS.md
- Keep examples aligned with rules

## Agent policy
- Use images as primary evidence when vision is available
- Use OCR only as fallback when vision is unavailable
- Prefer current state vs desired state comparisons
- Do not infer success without validation

## Handoff policy
- End meaningful work with SESSION.md or HANDOFF.md updates when continuity matters
