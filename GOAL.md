# Goal

## Primary goal
Create a repository that clearly teaches an agent how to understand the current screen state and the desired final screen state.

## Immediate goal
Ensure an agent can understand that the full desktop screenshot is not the final target and that the final target is a clean screen with only the terminal visible.

## Success criteria
- The agent can distinguish current state from desired state.
- The agent can use images first when vision is available.
- The agent can use OCR and structured state only when vision is not available.
- The repository contains enough guidance to avoid confusion.

## Out of scope for now
- Full product implementation
- Advanced automation framework
- Rich multi screen workflows

## Priority
1. Clarity
2. Correct interpretation
3. Simple execution rules
