# Assumptions

## Current assumptions
- The repo is used by agents and humans together
- Some agents may have vision and some may not
- Visual references can be part of the source of truth
- OCR and structured UI state are fallback layers for non vision agents
- Session continuity matters
- The user values precision, clarity, and operational safety

## Review rule
Any assumption that becomes false should be moved into DECISIONS.md, RULES.md, or RISKS.md as appropriate.
