# ocweb

Project documentation repository.

## Visual references

This repository includes two important images for agent guidance.

- `images/estado_atual_tela_completa.png` = current state before cleanup
- `images/estado_desejado_apenas_terminal.png` = desired state after cleanup

Important:

- The full desktop image is only a record of how things looked before.
- The terminal only image is the expected final result.
- Agents should not confuse the current state image with the target state.

For stricter instructions, see `VISUAL_RULES.md`, `AGENTS.md`, and `CONTEXT.md`.
