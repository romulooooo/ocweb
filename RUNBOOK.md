# RUNBOOK

## Purpose
Operational steps for running and validating the repository workflow.

## Standard run sequence
1. Read `GOAL.md`
2. Read `AGENTS.md`
3. Read `VISUAL_RULES.md`
4. Compare current and desired references
5. Execute minimal actions to reach the desired state
6. Validate with `CHECKLIST.md`

## Validation
- Confirm only the terminal remains visible
- Confirm no conflict with repository rules
- Confirm the source files still match reality

## Recovery
If the state is unclear:
1. Stop actions
2. Re read visual guidance files
3. Re inspect the current state
4. Continue only after the state is clear
