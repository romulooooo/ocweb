# Quality

## Quality attributes
- Clarity
- Consistency
- Traceability
- Recoverability
- Low ambiguity
- Reusability

## Quality rules
- Every important claim should point to a file or artifact
- Every workflow should have a validation path
- Every example should match the documented rules
- Every new doc should have a reason to exist

## Review checklist
- Is the file necessary
- Is the file named clearly
- Is there a source of truth overlap
- Is the next action obvious
- Can another operator continue from this state
