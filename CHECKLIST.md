# Checklist

## Before starting
- Read `GOAL.md`
- Read `AGENTS.md`
- Read `CONTEXT.md`
- Check whether the agent has vision
- Confirm whether visual references are relevant

## Before making changes
- Understand the current state
- Understand the desired state
- Check related docs for overlap
- Avoid contradicting existing repository rules

## Before finishing
- Ensure the change matches the stated goal
- Ensure file names are self explanatory
- Ensure docs remain internally consistent
- Ensure non vision fallback files remain aligned with vision based files
- Update memory and state files if the repository meaning changed
- Prepare a clear commit message

## Success condition
- The repository should be understandable by both humans and agents
- The intended current state and desired state should be obvious
