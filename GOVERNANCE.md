# Governance

## Ownership model
This repo should have clear ownership for product intent, operating rules, and documentation quality.

## Governance rules
- Major operational rule changes should be recorded
- New high value docs should be indexed
- Deprecated docs should be marked clearly
- Conflicts between docs should be resolved quickly

## Review cadence
Suggested review points:
- after major structure changes
- after workflow failures
- after ambiguous agent behavior
- before scaling the system to more agents or tasks
