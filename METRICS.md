# Metrics

## Repository metrics
- Time to understand repo purpose
- Time to find source of truth
- Time to determine next action
- Number of conflicting docs found in review
- Number of successful handoffs

## Agent metrics
- Correct interpretation rate of current vs desired state
- Validation before completion rate
- Need for human correction
- Repeatability across sessions

## Quality signal
Lower ambiguity and lower correction frequency indicate better repo maturity.
