# Success Criteria

## Global success
The repository should let a competent agent understand what exists, what is desired, what rules apply, and what next action is correct.

## Documentation success criteria
- Goals are explicit
- Rules are explicit
- Current state and desired state are explicit
- Sources of truth are explicit
- Handoff is possible without major context loss

## Visual task success criteria
- The agent can identify the current screen state
- The agent can identify the desired screen state
- The agent can explain the gap
- The agent can choose the next valid action
- Final state can be verified

## Failure signs
- Ambiguous file ownership
- Conflicting rules
- Missing next step
- Missing validation path
